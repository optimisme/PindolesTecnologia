# Lliçó 0 · Introducció a Git: versions, historial i col·laboració

**Format:** sense preguntes; pauses de lectura explícites; anglès en cursiva als subtítols.

## Capçalera i presentació

4 s de música comuna. Després, la veu llegeix:

> Lliçó zero. Introducció a *Git*.

## Un projecte canvia cada dia

Un projecte canvia cada dia. Afegim una pàgina, corregim un error o tornem a una idea anterior. Amb el temps, necessitem entendre com hem arribat fins aquí. *(pausa 2.5 s)*

Acumular carpetes amb noms com final i definitiu fa difícil saber què conté cadascuna. També complica combinar la feina de diverses persones. *(pausa 3 s)*

**Visual:** Un projecte web evoluciona; després, tres còpies amb noms final, final2 i final-definitiu mostren la dificultat de seguir els canvis.

## Git organitza la història del projecte

*Git* és un sistema de control de versions. Permet registrar l’estat d’un projecte i consultar després la seva evolució. *(pausa 2.5 s)*

Cada registre, anomenat *commit*, identifica una versió i inclou un missatge que explica el canvi. El repositori conserva aquest historial. *(pausa 3 s)*

**Visual:** Historial de tres versions identificades amb missatges. El conjunt forma part del repositori, sense mostrar comandes.

## Comparar ajuda a investigar

Podem comparar dues versions per veure què ha canviat. Si una modificació introdueix un problema, l’historial ens dona un punt de partida per investigar-lo. *(pausa 3 s)*

**Visual:** Dues versions de la mateixa pàgina amb la línia del menú modificada; fletxa cap a la comparació i ressaltat del canvi.

## El repositori local conserva les versions

*Git* funciona al teu ordinador. Pots registrar i consultar versions sense connexió a internet. La informació queda al repositori local. *(pausa 3 s)*

**Visual:** Ordinador amb historial propi. Es manté visible quan s’apaga la connexió a internet.

## Compartir i integrar la feina

*GitHub* és un servei on podem allotjar repositoris i compartir-los. És una de les eines que podem utilitzar amb *Git*. *(pausa 2.5 s)*

Cada persona pot treballar amb la seva còpia i compartir després les versions. La integració permet reunir els canvis i revisar el resultat. *(pausa 3 s)*

**Visual:** Dos ordinadors i un servei remot amb fletxes de compartir. Git i GitHub tenen etiquetes separades.

## Les decisions continuen sent nostres

El projecte no es registra a cada tecla. Nosaltres decidim quan guardem una versió a l’historial. Desar un fitxer a l’editor és una acció diferent. *(pausa 3 s)*

Una versió registrada tampoc garanteix que tot funcioni bé. Cal revisar els canvis i comprovar el resultat del programa. *(pausa 3 s)*

**Visual:** Editor i historial diferenciats. Desar al fitxer no crea un nou registre. Revisar i provar són passos humans.

## Registrar. Comparar. Col·laborar.

*Git* ens ajuda a conservar versions, entendre les diferències i coordinar la feina. Aquestes són les tres idees amb què comencem. *(pausa 3 s)*

A la lliçó següent prepararem l’ordinador per treballar amb *Git*. Després guardarem i publicarem la primera versió d’un projecte, pas a pas. *(pausa 3 s)*

**Visual:** Tres idees generals, ressaltades una per una. La pròxima lliçó introduirà les comandes.

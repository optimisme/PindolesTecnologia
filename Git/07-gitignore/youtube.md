**Descripció**

```text
Ignorar els fitxers que genera el programa i distingir-los dels que [[Git]] ja seguia.

Punt de partida: El programa fa servir un segon fitxer amb les salutacions i deixa un registre de cada execució. Fa temps, també vam confirmar per error un registre antic.

Ordres que surten al vídeo:
  python3 helloGit.py
  git status --short
  git check-ignore -v debug.log
  git ls-files
  git rm --cached app.log
  git add .gitignore
  git commit -m "Ignora els fitxers generats"

Practica-ho: En un projecte de pràctiques, genera un registre executant el programa i crea una regla per ignorar-lo. Comprova la regla amb git check-ignore i compara-ho amb un fitxer que ja estigui seguit.
Script per preparar el mateix punt de partida: Git/practiques/07-gitignore.sh

Lliçó anterior: 06 · Add interactiu: prepara només una part del fitxer
Lliçó següent: 08 · Branques: prova una idea sense tocar main

Llista: Píndoles de Git. Subtítols en català inclosos.
```

# Vídeos de la sèrie

Aquí hi van els MP4 finals de cada lliçó, amb el nom de la seva carpeta
(`08-branques.mp4`). Els escriu `python Git/eines/render.py Git/NN-nom` després de
verificar-los. La resta del que es produeix per a cada lliçó (subtítols, narració,
portada i informes) queda a `NN-nom/output/`.

Els vídeos no es versionen amb Git (vegeu `.gitignore`): es poden tornar a produir i
es publiquen a YouTube. Els vídeos de la numeració anterior són a
`arxiu/produccio-anterior/`.

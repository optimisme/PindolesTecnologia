# Introducció a Git: versions, historial i col·laboració

## Presentació (4,00–7.62 s)

Lliçó zero. Introducció a Git.

## Un projecte canvia cada dia (7.62–35.29 s)

**Animació:** Un projecte web evoluciona; després, tres còpies amb noms final, final2 i final-definitiu mostren la dificultat de seguir els canvis.

### canvis (8.00–21.41 s)

**Locució:** Un projecte canvia cada dia. Afegim una pàgina, corregim un error o tornem a una idea anterior. Amb el temps, necessitem entendre com hem arribat fins aquí.

**Pausa de lectura i assimilació:** 2.5 s; es manté el mateix visual.

### copies (21.41–34.71 s)

**Locució:** Acumular carpetes amb noms com final i definitiu fa difícil saber què conté cadascuna. També complica combinar la feina de diverses persones.

**Pausa de lectura i assimilació:** 3 s; es manté el mateix visual.

## Git organitza la història del projecte (35.29–61.21 s)

**Animació:** Historial de tres versions identificades amb missatges. El conjunt forma part del repositori, sense mostrar comandes.

### git (35.69–46.34 s)

**Locució:** Git és un sistema de control de versions. Permet registrar l’estat d’un projecte i consultar després la seva evolució.

**Pausa de lectura i assimilació:** 2.5 s; es manté el mateix visual.

### registre (46.34–60.65 s)

**Locució:** Cada registre, anomenat commit, identifica una versió i inclou un missatge que explica el canvi. El repositori conserva aquest historial.

**Pausa de lectura i assimilació:** 3 s; es manté el mateix visual.

## Comparar ajuda a investigar (61.21–75.58 s)

**Animació:** Dues versions de la mateixa pàgina amb la línia del menú modificada; fletxa cap a la comparació i ressaltat del canvi.

### diferencies (61.60–75.02 s)

**Locució:** Podem comparar dues versions per veure què ha canviat. Si una modificació introdueix un problema, l’historial ens dona un punt de partida per investigar-lo.

**Pausa de lectura i assimilació:** 3 s; es manté el mateix visual.

## El repositori local conserva les versions (75.58–90.13 s)

**Animació:** Ordinador amb historial propi. Es manté visible quan s’apaga la connexió a internet.

### local (75.98–89.54 s)

**Locució:** Git funciona al teu ordinador. Pots registrar i consultar versions sense connexió a internet. La informació queda al repositori local.

**Pausa de lectura i assimilació:** 3 s; es manté el mateix visual.

## Compartir i integrar la feina (90.13–115.71 s)

**Animació:** Dos ordinadors i un servei remot amb fletxes de compartir. Git i GitHub tenen etiquetes separades.

### servei (90.51–103.16 s)

**Locució:** GitHub és un servei on podem allotjar repositoris i compartir-los. És una de les eines que podem utilitzar amb Git.

**Pausa de lectura i assimilació:** 2.5 s; es manté el mateix visual.

### equip (103.16–115.15 s)

**Locució:** Cada persona pot treballar amb la seva còpia i compartir després les versions. La integració permet reunir els canvis i revisar el resultat.

**Pausa de lectura i assimilació:** 3 s; es manté el mateix visual.

## Les decisions continuen sent nostres (115.71–141.92 s)

**Animació:** Editor i historial diferenciats. Desar al fitxer no crea un nou registre. Revisar i provar són passos humans.

### decidir (116.10–130.38 s)

**Locució:** El projecte no es registra a cada tecla. Nosaltres decidim quan guardem una versió a l’historial. Desar un fitxer a l’editor és una acció diferent.

**Pausa de lectura i assimilació:** 3 s; es manté el mateix visual.

### provar (130.38–141.33 s)

**Locució:** Una versió registrada tampoc garanteix que tot funcioni bé. Cal revisar els canvis i comprovar el resultat del programa.

**Pausa de lectura i assimilació:** 3 s; es manté el mateix visual.

## Registrar. Comparar. Col·laborar. (141.92–166.83 s)

**Animació:** Tres idees generals, ressaltades una per una. La pròxima lliçó introduirà les comandes.

### resum (142.32–154.35 s)

**Locució:** Git ens ajuda a conservar versions, entendre les diferències i coordinar la feina. Aquestes són les tres idees amb què comencem.

**Pausa de lectura i assimilació:** 3 s; es manté el mateix visual.

### seguent (154.35–166.26 s)

**Locució:** A la primera lliçó pràctica veurem com preparar un canvi, confirmar-lo i publicar-lo. Ho farem pas a pas, amb un exemple complet.

**Pausa de lectura i assimilació:** 3 s; es manté el mateix visual.

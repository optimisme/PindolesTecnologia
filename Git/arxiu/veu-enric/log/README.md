# Prova de log i logs

El text enviat al servei de la lliçó gitignore conté literalment «punt log».
L’usuari sent «logaritme»: sembla una expansió de l’abreviatura matemàtica
per part del sintetitzador, no una substitució del guió o del renderitzador.

La prova utilitza `lòg` i `lògs`, amb la mateixa veu catalana masculina Enric,
a `+12%`, en tres contextos: extensió, fitxers de registre i comanda Git.

[Escoltar la prova](output/prova-log.mp3).
Mostra aprovada per l’usuari: les equivalències `log` → `lòg` i `logs` → `lògs`
s’han incorporat al glossari. S’actualitzen les cinc lliçons afectades.

```bash
.venv/bin/python arxiu/veu-enric/log/genera.py
```
